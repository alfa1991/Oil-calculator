# Oil industry calculator

Мобильный инженерный калькулятор для Android и iPhone. Пользователи: операторы добычи, инженеры-технологи, мастера, специалисты ТКРС и буровики. Расчёты выполняются на устройстве без интернета с обновлением результата при изменении параметров.

## Принципы

- Основные расчёты, справочник, история, скважины и экспорт доступны без регистрации и интернета.
- Формулы и исправления ошибок не зависят от оплаты. Монетизация не включается в первый этап.
- У каждой выпускаемой методики есть источник, версия, допущения, тесты и отчёт проверки.
- Пользователь настраивает видимость и порядок разделов; изменение формулы требует отдельной проверки.
- Конфиденциальные сведения не помещаются в GitHub, диагностику и рекламу.
- Облачная синхронизация добровольная и вводится после проверки защиты данных.
- Исходники публичны; лицензия на код пока не выбрана. Не добавлять сторонние книги, таблицы и изображения без проверки прав.

Развитие идёт по версиям. Обещание отсутствия ошибок и аварий не является технически проверяемым требованием; вместо него предусмотрены условия проверки и блокировки выпуска.
